# CODEX_WORKFLOW.md

Fluxo ideal de trabalho do Codex neste projeto.

## Para toda nova tarefa
1. Ler `AGENTS.md`.
2. Ler `PROJECT_CONTEXT.md`.
3. Ler `TASKS.md`.
4. Ler `CHANGELOG_CODEX.md` apenas se precisar entender historico recente.
5. Identificar os arquivos minimos necessarios para a tarefa.
6. Confirmar mentalmente o escopo.
7. Alterar somente o necessario.
8. Validar a alteracao de forma proporcional.
9. Atualizar `PROJECT_CONTEXT.md` se houver nova decisao importante.
10. Atualizar `TASKS.md` com status.
11. Atualizar `CHANGELOG_CODEX.md` com resumo curto.
12. Responder ao usuario de forma objetiva.

## Regra de economia
- Nao reprocessar o projeto inteiro.
- Nao abrir arquivos irrelevantes.
- Nao explicar raciocinio longo.
- Nao repetir contexto ja salvo.
- Nao usar a conversa como fonte principal quando os arquivos de contexto existirem.
- Nao executar comandos pesados se uma checagem leve resolver.

## Padrao de resposta
- Arquivos alterados.
- O que foi feito.
- Como validar.
- Pendencias ou bloqueios, se existirem.

## Atualizacao dos arquivos de contexto
- `PROJECT_CONTEXT.md`: atualizar somente quando houver decisao, padrao, estrutura ou estado importante.
- `TASKS.md`: manter tarefa atual, status, criterios e proximos passos.
- `CHANGELOG_CODEX.md`: registrar data, tipo, arquivos alterados, resumo, validacao e proxima acao.
